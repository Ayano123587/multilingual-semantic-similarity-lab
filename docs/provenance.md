# Data and encoder provenance

The [SemRel2024 paper](https://arxiv.org/html/2402.08638v5), sections 3.1.2 and 3.2, identifies news-source Amharic, Hausa and Kinyarwanda pairs and native-speaker best–worst relatedness judgments. Relatedness includes topical association and is broader than paraphrase equivalence. The [official task repository](https://github.com/semantic-textual-relatedness/Semantic_Relatedness_SemEval2024) is pinned to `3c5941ddffdc9d833a5528f49dd13ed9087c0dba`; all nine CSV SHA256 values are constants in `src/config.py`. No generated sentences, translations, synthetic ratings, or pseudo-labels enter this study. English/Marathi/Telugu were rejected during source preflight; the original proposal remains as history.

No explicit dataset license was found in the inspected repository/card; the authors release the corpus for relatedness research. This does not establish unrestricted redistribution rights for upstream news text. All raw text, ratings, processed inputs, caches and learned artifacts remain private/ignored. Original source code alone is MIT licensed.

[Davlan/afro-xlmr-base](https://huggingface.co/Davlan/afro-xlmr-base/tree/25f27299c247a6b73a767bd82d12444138b19337) is pinned to revision `25f27299c247a6b73a767bd82d12444138b19337`. Its pinned model card declares MIT and describes masked-language-model adaptation of XLM-R on African languages, including all three study languages. It is not a sentence-similarity-fine-tuned encoder. The pipeline loads the backbone with `add_pooling_layer=False`, refuses missing/mismatched encoder keys, and permits only unused MLM-head keys. Attention-mask mean pooling and L2 normalization replace any random pooler. Max length is 128 tokens; truncation counts and actual weight SHA256 are recorded after execution.

The encoder's pretraining source overlap with these news sentences is unknown. Frozen-encoder and lexical comparisons do not establish independent document/location transfer. Official splits contain sentence-connected components crossing partitions; pair-copy removal does not make them sentence-disjoint. Clustered uncertainty is descriptive and cannot eliminate upstream overlap or repeated validation-selection optimism.

Private cloud source transport consists of ordinary readable Python files with an explicit path/SHA256 manifest. The small checked-in runner imports those files. No encoded code literals, hidden loaders, data in Git, or synthetic replacement datasets are used.
